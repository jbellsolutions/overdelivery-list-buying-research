Research sponsors inside Claude

Connect SponsorGap to Claude as an MCP server. Ask plain-English questions about brands, niches, and budgets — without leaving your AI workflow.

1
Generate your API key
Go to Settings → API Keys in your SponsorGap account and create a key.
2
Add the MCP server in Claude
Open Claude Settings → Integrations and add a new MCP server:
https://sponsorgap-mcp-cc7ac08f6c89.herokuapp.com/mcp
3
Authenticate with your key
Claude will redirect you to enter your SponsorGap API key. Paste it in and connect.
4
Ask anything about sponsors
Start a conversation in Claude and ask about brands, niches, or competitors naturally.
